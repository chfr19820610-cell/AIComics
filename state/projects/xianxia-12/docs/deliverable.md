# 《封印之下》立项文档

**项目代号**：`xianxia-12` ｜ **体裁**：东方仙侠 · 竖屏 AI 漫剧 ｜ **体量**：12 集 × 45–60 秒 × 6 分镜

---

## 一、项目名与基础信息

| 项目 | 内容 |
|---|---|
| 剧名 | 《封印之下》 |
| 备选名 | 《最后一道锁》《九锁》 |
| 题材 | 仙侠（东方修真，非西幻） |
| 集数 / 时长 | 12 集，单集 45–60 秒（纯分镜 6×7=42 秒，加片头钩子卡与结尾字幕卡补足） |
| 画幅 | 9:16 竖屏 |
| 分镜总量 | 72 个 shot（每集 6 个，S01–S06） |
| 投放平台 | 抖音（主）／快手（次） |
| 制作管线 | 文生图分镜 → 图生视频 → AI 配音 → 竖屏剪辑，沿用项目内置 `cultivation` 模板五幕骨架 |
| 目标数据 | 3 秒完播率 ≥ 55%，单集完播率 ≥ 35%，12 集连刷率 ≥ 15% |

## 二、一句话 logline

全宗都笑他是丹田被封的废物，直到天雷降下、封印替他挡下第一击——他才明白那道锁不是困住他的枷锁，而是天道要抹杀他之前，最后一道护命的屏障。

## 三、目标受众

- **核心盘（约 60%）**：18–35 岁男性，仙侠/逆袭爽文与有声书存量用户，三四线城市与下沉市场为主，学生、蓝领、新市民居多。他们要的是「被踩到底 → 立刻还手」的即时反馈，不介意设定简单，只介意不爽。
- **次核心（约 35%）**：25–40 岁女性，被「苏璃当众反水护人」的立场戏与「锁链/雷纹」的视觉美学吸引，是二创与话题扩散的主力。
- **边缘盘（约 5%）**：仙侠品类重度用户，负责在评论区考据世界观、抬热度。
- **观看场景**：通勤、午休、睡前，单次 3–10 分钟，天然适配「一次连刷 12 集」的投流承接页。
- **算法适配**：竖屏、强冲突、单集闭环，任何一集都能独立作为投流素材，不依赖前情。

## 四、核心爽点

1. **极致反差**：E01 被泼脏水跪地擦石板，E09 同一座山门全宗长老跪着迎——首尾镜像，观众一眼看懂逆袭幅度。
2. **即时打脸**：每集至少一次「看轻他的人当场吃瘪」，平均 42 秒内完成「打压—还手—对方震惊」小闭环。
3. **异象奇观**：锁链吞天雷、雷刀劈雷云、雷海冲天，全部用粒子特效呈现，是竖屏划走率的最低点。
4. **反常识能力**：别人渡劫求活命，他拿天雷当饭吃、炼成兵器——「逆炼诛杀之力」是本剧独有爽点。
5. **身份三级跳**：废物 → 灾星 → 天道的备份，每次身份升级都伴随一次全宗态度翻转。
6. **情感站队**：苏璃在雨夜当众横剑，一句「我守的是他，不是封印」，把爽点从「打脸」升级为「有人为我背叛世界」。
7. **金句记忆点**：「我守的是他，不是封印」「这次，我自己锁」——可直接做封面大字与评论区置顶。

## 五、差异化卖点

1. **概念反向**：市面仙侠短剧 90% 是「解封变强」，本剧是「解封即招天罚」。封印不是枷锁而是护盾——这个反常识设定本身就是最强的三秒钩子。
2. **双反转结构**：E06 完成剧作层反转（封印在护他），E12 完成哲学层反转（天道不是要杀他，是要拦他）。一次投流可拆出两条完全不同卖点的素材。
3. **视觉锚点统一**：暗金锁链纹 + 雷纹 + 金瞳，三个符号贯穿 72 个分镜，每集至少一次特写。可直接延展为封面、贴纸、二创模板与账号视觉资产。
4. **女性角色不做工具人**：苏璃有独立立场与独立动作（挡剑、反水、守人），她的选择本身就是钩子，能吃到女性向流量。
5. **单集即素材**：6 镜结构天然适配投流切片，任何一集都能单独投放，不需要观众先看第一集。

## 六、世界观与角色速查（制作一致性用）

- **规则**：天道每千年降下「诛杀之雷」，抹除被判定为威胁的「天弃之子」。九位大能曾以九道锁链封住一个婴儿的力量，对外宣称是「废柴封印」，实为护命屏障。千年后九锁只剩三道。
- **林昭**：17 岁，杂役，黑发半束，灰麻布衣，右腕缠旧布条遮纹。视觉弧线：灰布 → 破衣染血 → 雷纹缠身 → 金袍残影。
- **苏璃**：19 岁，内门首席，高马尾，月白剑袍，眉心朱砂。立场弧线：旁观 → 握剑犹豫 → 横剑挡人 → 剑指宗门。
- **老墨**：守碑人，灰袍瞎眼，铁杖，实为第一个天弃之子，胸口只剩一道锁。
- **玄尘子**：掌门，白发长须，知道「天道备份」的真相但一直不敢说。
- **严崇**：执法长老，铁面黑红法袍，宗门的刀，负责制造压迫。
- **天道使者 / 金袍人形**：白衣无面金瞳 → 金光凝成的金袍人形，全剧最强者，终局却向他下跪。

**曲线读法**：整体是「双峰一收」——E01 谷底起步，E03 给第一口糖，E06 打出全剧第一大爆点，E07 主动降速做情感戏（为女性向观众留呼吸口），E09 打出打脸最高峰，E10–E12 三集升维收束，把爽剧抬成「宿命悲剧 + 续作预告」。

**前 3 集快节奏机制**：E01 开场 3 秒就是脏水泼脸，不做任何世界观铺垫；E02 在 24 小时内接上封印吞雷的异象与禁令；E03 立刻把主角扔进妖兽坑完成反杀。三集之内完成「受辱 → 异象 → 还手」的完整爽感闭环，观众不需要耐心。

**单集独立看懂机制**：每集 S01 只用 1 句话字幕交代前情；每集内部必须有一次「被打压 → 还手/反转」的小闭环；结尾钩子只抛问题、不抛新设定，保证新观众能直接看第 6 集也懂。

**连续剧机制**：以「锁链纹」的裂开进度作为全剧进度条（九锁 → 剩三道 → 第二道裂于 E05 → 第一道断于 E06 → 第二道崩于 E08 → 第三道崩于 E11 → E12 重铸），观众靠数锁就能感知剧情推进。

**时长口径**：6 个分镜 × 7 秒 = 42 秒正片，加 1–3 秒片头钩子卡与 2–5 秒结尾字幕/钩子定格，成片落在 45–50 秒，符合平台 45–60 秒要求。

## 八、视觉与制作规范

- **色彩**：宗门段落用冷青灰 + 雾白；封印/雷段落用暗金 + 电紫；天道段落用高饱和金。三色分区让观众一眼判断「现在是谁的主场」。
- **角色锚点**：林昭的右腕旧布条、苏璃的剑柄缠绳、老墨的眼布、玄尘子的断指玉扳指——四件小道具保证 AI 出图跨集一致性。
- **镜头语言**：压抑段用俯拍与低机位仰拍交替；爆发段用环绕、甩镜、高速摄影；每集至少一个「竖屏满幅」的垂直构图（如天梯、雷柱）适配 9:16。
- **封面策略**：优先用「金瞳」与「锁链纹」两个符号做封面主体，人物半张脸 + 大字，保证在信息流小图状态下也能识别。

## 九、投放与运营建议

- **标题**：直接使用每集 `publish_title`，全部包含「反差 + 悬念」双要素，控制在 20 字内，前 8 字必须是钩子。
- **封面大字**：`cover_text` 控制在 6 字内，用最大字号压在人物脸上，保证小图可读。
- **切片策略**：E01、E03、E06、E09 作为四条主力投流素材，分别打「受辱」「反杀」「反转」「打脸」四个人群标签。
- **A/B 测试**：E06 准备两版开头——A 版从「天雷劈下」切入，B 版从「苏璃握剑的手」切入，用女性向素材测第二人群。
- **评论区运营**：置顶「数一数他胸口还剩几道锁」，把进度条机制变成互动话题。

## 十、风险与规避

| 风险 | 表现 | 规避 |
|---|---|---|
| 概念理解门槛 | 观众没看懂「封印是护盾」 | E01/E02 用最直白台词点明，E06 用画面再讲一遍 |
| 中段掉速 | E07 情感戏拉低爽感 | E07 压缩到 42 秒，钩子直接接 E08 能力爆发 |
| AI 出图不一致 | 角色跨集漂移 | 固定四件道具 + 四视图参考图 + 分镜督导审核 |
| 反转过度 | E12 哲学反转劝退爽剧用户 | E12 保留「重钉锁链」的强动作场面，先给爽感再给余味 |
| 续作依赖 | 结尾钩子太开放 | E12 单集内完成「他为什么自愿封印」的完整回答，钩子只留一句敲门声 |
