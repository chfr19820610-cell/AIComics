# COMPLIANCE — 合规红线

> SOP §9 与上一篇 §10 的落地版。**任何一条不满足，禁止发布。**

---

## 1. 硬红线（违反即驳回）

| # | 红线 | 检查方式 |
|---|---|---|
| R1 | 必须标注「AI 生成」标识 | 成片首帧/角落水印 + 平台字段 |
| R2 | 禁止真人肖像侵权 | 角色均为原创，无真实人物对应 |
| R3 | 禁止血腥特写过载 | 血液镜头 ≤ 1 处/集，且非特写 |
| R4 | 禁止涉政/涉宗教敏感 | 无现实宗教符号、无政治隐喻 |
| R5 | 禁止未成年人受虐暗示 | 主角年龄设定 16+，受辱镜头用象征手法 |
| R6 | 禁止搬运他人 BGM/音效 | 仅用 CC0/自制 |
| R7 | 微短剧备案号（如平台要求） | `publish/E*.json` 填 `filing_no` |

## 2. AIGC 标识规范

```
位置：画面右下角
内容：AI 生成
样式：半透明白字，字号 24px，不遮挡主体
时长：全程显示
```

## 3. 平台差异

| 平台 | 额外要求 |
|---|---|
| 抖音 | 需「内容由 AI 生成」标签 + 备案号 |
| 快手 | 需 AIGC 标识 + 人工复核记录 |
| 视频号 | 需原创声明 |
| 小红书 | 需 AIGC 标识 + 不诱导 |

## 4. 敏感词/画面自检

- 台词：过滤政治/宗教/色情敏感词
- 画面：过滤血腥特写、恐怖元素、擦边构图
- 音乐：只用 CC0 或自制

## 5. 发布前 checklist（人审卡点 5）

- [ ] AI 标识已烧录
- [ ] 备案号已填（如平台要求）
- [ ] 敏感词扫描 0 命中
- [ ] 血液镜头 ≤ 1 处/集且非特写
- [ ] 无真人肖像
- [ ] BGM 为 CC0/自制
