# STYLE — 风格总纲

> 整合自 `docs/style_bible.json` + `docs/uiux_visual_spec.json`。
> **本文件是风格 SSOT，任何 prompt 必须与此一致。**

---

## 1. 风格定位

| 项 | 值 |
|---|---|
| 风格 | 东方仙侠 · 赛璐璐动漫 |
| 线条 | 粗黑描边（bold black outlines） |
| 上色 | 扁平赛璐璐（flat cel shading） |
| 光影 | 暗调电影光（cinematic low-key） |
| 色调 | 冷蓝灰为主，金/雷为高光色 |
| 画幅 | 9:16 竖屏 |

## 2. 核心 prompt 前缀（必须每条都带）

```
2d anime, flat cel shading, bold black outlines, hand-drawn animation,
Japanese anime style, xianxia wuxia, animation frames, <场景描述>
```

### 实测补充（防 Q 版漂移）

特写/群像镜头额外加：
```
serious tone, dramatic, not chibi, realistic proportional anatomy
```

## 6. 运镜规范

| 镜型 | 运镜 | 时长 |
|---|---|---|
| 大特写 | 固定/微推 | 2–3s |
| 近景 | 轻推 | 3s |
| 中景 | 跟/摇 | 3s |
| 全景/俯视 | 固定/慢拉 | 3s |
| 动作镜 | 快切/甩 | 2s |

## 7. 禁止项

- ❌ 写实照片风、3D 渲染风
- ❌ Q 版/大头娃娃（除非明确标注为回忆/搞笑段落）
- ❌ 现代元素（手机/汽车/西装）
- ❌ 日式和风（和服/神社）
- ❌ 西方奇幻（城堡/精灵）
