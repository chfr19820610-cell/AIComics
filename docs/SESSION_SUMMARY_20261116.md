## 八、最重要的一条教训

> **工具看起来正常，但结果是错的。**
>
> **解法：用真实样本验证工具，而不是相信工具的输出。**

**本次会话发现的所有问题（§18/§19/§20/§21/§22/§23）都是这个模式：**
- gate 检查旧数据 → 假通过
- 代码没匹配正确数据 → 静默失效
- 中间表示改了，最终输入没改
- 分类器词表缺陷 → 系统性低估
- 模型能力限制 → 无法修复
- prompt 元语言 → 模型画出来

**每一条都是"看起来正常但实际错了"。**
