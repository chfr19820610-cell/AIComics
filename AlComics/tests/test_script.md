# AIComics 红蓝对抗测试剧本

## 场景
一个赛博朋克主题的短篇故事，用于测试三层Agent编排器。

## 角色
- 主角：林夜，28岁，黑客
- 配角：艾琳，AI研究员
- 反派：零号公司CEO

## 故事梗概

### 第一幕：入侵（约1分钟）
林夜在霓虹闪烁的赛博空间中，通过神经接口入侵零号公司的数据中心。
他的手指在虚拟键盘上飞舞，数据流如瀑布般从眼前划过。
突然，警报响起，安保AI启动防御系统。

### 第二幕：追逐（约1分钟）
林夜在数字迷宫中穿梭，躲避追踪程序的围捕。
他打开加密通道，呼叫艾琳支援。
艾琳远程注入干扰程序，让追踪AI陷入循环。

### 第三幕：结局（约1分钟）
林夜成功获取关键数据，退出神经接口。
零号公司CEO在办公室收到入侵警报，愤怒地砸碎了咖啡杯。
林夜与艾琳在安全屋汇合，分析数据。
