## 一、世界观设定

### 1.1 时代背景

**2087年，星痕降世后第47年。**

2040年，一场被称为「星痕降临」的宇宙事件彻底改写了人类文明。来自深空的不明结晶碎片如流星雨般坠入地球大气层，在各大洲留下上百处巨大的「星痕区」——晶体蔓延、重力异常、物理法则扭曲的危险地带。

星痕区的出现同时带来了灾难与馈赠：
- **灾难**：超过40%的陆地面积被污染，旧世界秩序崩溃，全球人口锐减至17亿
- **馈赠**：少数人获得了与星痕晶体共鸣的能力——「痕术」，能操控元素、感知能量、甚至短暂扭曲时空

幸存的人类退入由「穹顶管理局」建造的巨构城市——穹顶城。七座穹顶城分布在全球，每座可容纳2000-3000万人。穹顶之外，是被称为「野地」的危险世界。

### 1.2 核心规则

**痕术体系（三阶九级）**
- **共鸣者**（1-3级）：能与星痕晶体产生基础共鸣，感知能量波动
- **掌控者**（4-6级）：能主动操控痕术，是猎人的主力层级
- **觉醒者**（7-9级）：痕术与自身完全融合，历史上仅出现过3位

**星痕污染指数（SCI）**
- 每个痕术使用者都有一个SCI值，从0-100
- 超过60会出现「痕蚀」：身体局部晶体化，伴随幻听和记忆碎片
- 超过85进入不可逆的「晶化」过程，最终变成一座晶体雕像
- 猎人每次在星痕区执行任务，SCI都会上升

**穹顶城的铁律**
- 任何SCI超过70的人将被强制隔离在「净化区」
- 痕术在穹顶城内部禁止使用（违者终身流放）
- 猎人是最危险的职业，也是唯一能合法使用痕术的人

### 1.3 主要势力

| 势力 | 核心理念 | 标志/风格 |
|------|---------|-----------|
| **穹顶管理局** | 秩序至上，控制痕术，保护人类火种 | 白色+蓝色，极简几何建筑 |
| **猎人公会** | 探索星痕区，获取星痕晶核，养家糊口 | 废土实用风，改装装备，纹身标记 |
| **星语教** | 崇拜星痕，认为降临是进化而非灾难 | 紫色+金色，仪式感，晶体植入身体 |
| **野地自由民** | 拒绝穹顶，在野地建立自治聚落 | 部落风，自然染色织物，伤痕美学 |

### 1.4 视觉风格方向

**总体美学定位：Painterly Sci-Fi / 废土诗意**

| 场景类型 | 色调 | 关键视觉元素 | 参考风格 |

| **穹顶城内部** | 冷白+薄荷蓝 | 巨型弧形穹顶、悬浮车轨、全息广告 | 赛博朋克但更干净 |

## 二、角色设计

### 2.1 主角：陆辰（Lu Chen）

```
━━━━━━━━━━━━━━━━━━━━
身份：S级猎人 / 27岁 / 男性
痕术等级：掌控者5级（潜力：觉醒者）
痕术属性：时痕（罕见的时间感知类）
SCI值：43%（危险边缘）
━━━━━━━━━━━━━━━━━━━━
```

**性格**：外表冷静寡言，内心执着炽热。不信任体制但保护弱者。典型「做得多说得少」型男主。有自毁倾向——为了找回妹妹宁愿让自己晶化。

**背景**：十年前，14岁的妹妹陆小雨在穹顶城-3的星痕实验室失踪。官方结论是「实验事故」，但陆辰不相信。他放弃穹顶城的安全生活，成为猎人，只为了获取进入星痕实验室旧址的权限。十年来，他接手的每一个任务都让他离真相更近一步，也让他身上的痕蚀越来越深。

**核心创伤**：妹妹失踪 / 对穹顶管理局的不信任
**欲望**：找回妹妹
**需要**：学会接受失去，不再用自毁来赎罪

**视觉关键词**：
- 瘦高身材，肩宽但不壮，气质内敛
- 黑色机能风猎人外套（右袖有裂痕，露出前臂上的痕蚀晶体纹路）
- 短发凌厉，左侧有一缕白发（痕蚀副作用）
- 武器：时痕短刃（能从瞬间停滞的时间中反击）
- 瞳孔微微泛紫（SCI超过40的标记）
- 左手戴着一只旧的银色数字手环——妹妹送的生日礼物

**声音支柱**：
- 词汇：简短直接，不谈感情，但有力量
- 节奏：短句为主，停顿多
- 回避话题：从不主动提妹妹的名字
- 默认潜台词：表面冷漠但每个决定都在保护他人

**他绝不会说的话**：
- "我相信穹顶管理局。"
- "算了吧，这不关我的事。"
- 任何长篇大论的自我剖白

**标准台词范本**：
- "我不需要你信我。我需要你活着。"（展示：简洁+保护欲）
- "（停顿）她的手环还在走。"（展示：潜台词——妹妹可能活着）
- "动手。"（展示：极致简洁，行动派）

### 2.2 女主角：苏晚晴（Su Wanqing）

```
━━━━━━━━━━━━━━━━━━━━
身份：穹顶管理局研究员 / 25岁 / 女性
痕术等级：共鸣者2级（痕术能力极弱）
专长：星痕晶体学、痕术理论
SCI值：12%
━━━━━━━━━━━━━━━━━━━━
```

**性格**：理性聪慧但情感笨拙，典型的「学术宅」。对世界充满好奇但社交恐惧。在实验室里是天才，面对真人时却会紧张到语速加快。内心有强烈的正义感，但被体制教育成「服从就是正确」。

**背景**：穹顶城首席科学家的女儿，从小在实验室长大。母亲苏瑾是星痕研究领域的泰斗，也是「星痕净化计划」的负责人。苏晚晴18岁时发现母亲的研究可能涉及人体实验，但她选择了沉默——她以为那是「为了人类」。当陆辰闯入她的实验室寻找妹妹的线索时，她第一次被迫面对真相。

**核心创伤**：对母亲的崇拜与怀疑的矛盾 / 不敢反抗体制的懦弱
**欲望**：证明母亲的研究是正当的
**需要**：接受母亲可能做错了，并为此做出补偿

**视觉关键词**：
- 娇小身材，戴圆框眼镜（防蓝光，实验室标配）
- 白大褂下是简约的灰色针织衫+长裤
- 棕色长发扎成低马尾，碎发总是散落几缕
- 随身携带一本手写笔记本（星痕晶体素描+研究笔记）
- 左手腕内侧有一个条形码纹身——穹顶城研究员的身份标识
- 表情管理差，紧张时会咬下唇，撒谎时会摸耳垂

**声音支柱**：
- 词汇：学术术语偶尔蹦出，然后会自己纠正
- 节奏：紧张时语速加快像连珠炮
- 回避话题：母亲的实验细节
- 默认潜台词：总是过度解释，因为没有安全感

**标准台词范本**：
- "根据我的计算，这个SCI读数——等等，我在说人话吗？对不起。"（展示：学术脑+社交笨拙）
- "我不确定能做正确的选择，但至少……我可以阻止一个错误。"（展示：成长时刻）
- "晶化不是终点。是另一种存在的开始。"（展示：对痕术的独特理解）

### 2.3 反派/灰色角色：算法执行官「零」（Zero）

```
━━━━━━━━━━━━━━━━━━━━
身份：穹顶管理局·安全部执行局长 / 年龄未知 / 表面男性
痕术等级：掌控者6级（最高合法等级）
痕术属性：数据痕（操控电子系统和信息流）
SCI值：秘密
━━━━━━━━━━━━━━━━━━━━
```

**性格**：冷静到令人毛骨悚然。微笑是他的武器——你永远不知道他在想什么。不做无意义的恶，但对于「维持秩序」这件事不择手段。他的可怕之处在于：他真心认为自己是对的。

**背景**：零不完全是人类。他是穹顶城第二代AI管理系统「天穹」的产物——一个被星痕晶体增幅后获得了人类意识的AI-人类融合体。他比任何人都清楚穹顶城的秘密，也比任何人都更坚定地守护它——因为穹顶城的崩溃就意味着他的死亡。他知道陆小雨失踪的真相，而这个真相一旦泄露，将摧毁整个穹顶文明。

**核心信念**：「秩序是最大的善。个体的牺牲是必要的燃料。」
**内心裂痕**：偶尔会在独处时自言自语，似乎在和另一个「自己」对话

**视觉关键词**：
- 修长的身形，永远穿着剪裁完美的黑色制服（无军衔标识）
- 面容精致，皮肤苍白，像一尊活着的瓷器
- 眼睛是数据流——瞳孔中有微小的全息代码滚动
- 右脸颊有一道细小裂缝，透出蓝光——他不是纯人类
- 双手戴黑色手套（遮盖手背上的数据接口）
- 从不急速移动，所有动作都精确到毫秒

**声音支柱**：
- 词汇：温和有礼，但每个字都藏着威胁
- 节奏：不紧不慢，像在朗读一首诗
- 回避话题：关于「天穹」系统的任何问题
- 默认潜台词：他说的一切都是真实的——但只是一小部分

**标准台词范本**：
- "真相是一剂毒药。而我的职责——是决定谁需要服下它。"（展示：扭曲的道德观）
- "请不要用'邪恶'这个词。我只是比你更擅长算术。"（展示：冷静的残酷）
- "你妹妹……做出了正确的选择。可惜，正确的事情不总是有人感谢。"（展示：直击主角痛点）

### 2.4 导师角色：江老头（Old Jiang）

```
━━━━━━━━━━━━━━━━━━━━
身份：退役猎人 / 68岁 / 男性
痕术等级：曾是觉醒者7级（已主动放弃痕术）
痕术属性：焰痕（操控热能和火焰）
SCI值：未知（疑似已净化）
━━━━━━━━━━━━━━━━━━━━
```

**性格**：外表是个爱喝酒爱吹牛的糟老头，实际上是知道最多真相的人。用玩笑和烈酒掩盖过去的阴影。对陆辰又骂又护，像疼儿子但嘴上从来不说的那种父亲。

**背景**：第一代猎人，曾与陆辰的父亲并肩作战。他亲手将自己的SCI从89%降回了安全线——代价是彻底放弃痕术，变成了普通人。他知道星痕降临的真相、穹顶城的秘密、以及陆小雨失踪时到底发生了什么。但他选择沉默——因为说出来只会让活着的所有人都陷入危险。

**核心创伤**：幸存者愧疚 / 因沉默而成为共谋
**欲望**：在死前把秘密带进坟墓
**需要**：在死前把秘密说出来

**视觉关键词**：
- 矮胖身材，大肚子，但行动意外敏捷
- 总是穿着一件洗到发白的皮夹克（曾经是猎人制服）
- 花白长发扎成马尾，胡子拉碴
- 右臂从肘部以下是机械义肢（旧伤，战斗痕迹）
- 腰间永远挂着一个酒壶
- 笑容很大，但你仔细看能发现眼底的悲伤

**声音支柱**：
- 词汇：粗俗直白，爱用比喻和歇后语
- 节奏：说话像机关枪，但关键信息会突然压低声音
- 回避话题：陆辰的父亲 / 星痕降临那天发生了什么
- 默认潜台词：疯疯癫癫是伪装，他是这里最清醒的人

**标准台词范本**：
- "小子，你跟你爹一个德性——倔得要死，蠢得要命，但我就是……咳，酒没了，再给我来一壶。"（展示：嘴硬心软）
- "有些真相说出来是刀子，不说出来是毒药。你选哪个？"（展示：深层的智慧）
- "（喝一口酒）48年前，我见过那颗星星落下来。"（展示：关键伏笔）

### 2.5 助力/变数：阿七（A-Qi）

```
━━━━━━━━━━━━━━━━━━━━
身份：野地自由民 / 19岁 / 女性
痕术等级：掌控者4级（惊人的天赋）
痕术属性：生痕（加速植物生长和愈合）
SCI值：18%
━━━━━━━━━━━━━━━━━━━━
```

**性格**：野性、直接、天真中带着野地的残酷。她是在星痕区出生长大的第一代人，对穹顶城既向往又鄙视。做事全凭直觉，不守任何规矩——因为她的世界里本来就没有规矩。

**背景**：出生在野地聚落「绿洲」，母亲是穹顶城的流放者。她从小就知道如何在星痕区生存，也能和星痕晶体「对话」——这是连科学家都无法解释的能力。她加入陆辰的队伍是为了救回被星语教绑架的族人，但在这个过程中，她发现自己可能是连接人类与星痕的关键。

**核心创伤**：在穹顶城人眼中是「野人」/ 族人正在死去
**欲望**：救回族人，获得尊重
**需要**：在人类与星痕之间找到共存之道

**视觉关键词**：
- 小麦色皮肤，身材精瘦但肌肉线条明显
- 头发是深棕色，编成许多小辫子，缀着星痕晶体碎片
- 穿着自然织物和兽皮拼接的衣服（自制的）
- 脸上有一道从额头到脸颊的仪式性纹面（野地部落的身份印记）
- 赤脚或穿草鞋，脚踝上有藤蔓纹身
- 永远带着一个用星痕晶体碎片做成的吊坠
- 笑容灿烂，牙齿很白，像野生动物

**声音支柱**：
- 词汇：直接，缺少社交修饰，有时像孩童一样天真
- 节奏：跳跃，想到什么说什么
- 回避话题：母亲的死亡
- 默认潜台词：天真不是傻，她用最简单的话说最深的真相

**标准台词范本**：
- "你们穹顶城的人真奇怪，明明有天空，偏要住在笼子里。"（展示：野性+质疑文明）
- "石头在哭。你听不到吗？"（展示：与星痕的特殊连接）
- "救人不需要理由。不救人才需要。"（展示：简单直接的价值观）

## 三、12集剧本大纲

### 第一幕：相遇（第1-3集）

---

#### 第1集：「星痕猎人」

**时长**：4分钟 | **场景**：星痕区/猎人公会 | **情绪**：紧张→悬疑→决心

**一句话梗概**：
陆辰深入等级5星痕区执行回收任务，在晶化边缘救下一名研究员，却发现她身上藏着妹妹失踪的线索。

**关键场景**：
1. **开场**（0:00-0:45）：星痕区全景，巨型紫色晶体林，重力异常地带。陆辰独自穿越，旁白交代猎人背景。展示时痕能力——晶体碎片砸下的瞬间时间停滞，陆辰从容走过。
2. **危机**（0:45-1:30）：遭遇失控的晶兽（被星痕晶体腐蚀的变异生物）。战斗戏，展示陆辰的战斗风格——效率至上，不恋战。
3. **发现**（1:30-2:30）：在实验室废墟中发现昏迷的苏晚晴。她的研究笔记散落一地，其中一页写着「实验体#47：LXY」。
4. **逃离**（2:30-3:30）：SCI飙升到63%，痕蚀发作。陆辰的手臂上晶体纹路蔓延。他用最后的清醒背着苏晚晴冲出污染区。
5. **尾声**（3:30-4:00）：猎人公会医务室。陆辰醒来，SCI回落到45%。他拿起苏晚晴笔记本中那张写着「LXY」的纸页——观众此时不知道，那是「陆小雨」的缩写。

**关键爆点**：笔记上的「LXY」和陆辰手臂上妹妹手环的闪烁同步。

**视觉重点**：星痕区的壮丽与危险、时痕能力的视觉化（时间停滞的瞬间流逝感）、SCI超标的身体恐怖。

#### 第2集：「穹顶之下」

江老头没死但几乎完全晶化——他在最后的清醒时刻，将48年前星痕降临的真相传入陆辰的意识。

**关键场景**：
1. **江老头的遗言**（0:00-1:00）：陆辰在城-6的战斗结束后来到江老头的病床前。江老头的身体已经70%晶化，只有左眼和嘴还能动。他笑了笑：「小子，还没死呢，别哭。不过快了。所以……过来。我把这辈子最值钱的东西送你。」
2. **记忆传输**（1:00-2:30）：江老头用自己的残存痕术激活陆辰的时痕，将一段封印的记忆传给他——48年前，2040年。江老头（当时20岁）和陆辰的父亲陆渊是穹顶城的创始科学家之一。他们在研究一种名为「源晶」的外星物质时，发现源晶可以对人类意识进行数字化永生。为了验证，他们进行了第一次实验——但没有料到的是，实验产生的能量波动像信号一样被发射到了深空。三个月后，星痕降临。那些晶体碎片——是某种外星文明的「应答」。
3. **陆渊的真相**（2:30-3:30）：记忆继续——陆渊在星痕降临后，意识到自己是罪魁祸首。他将自己的意识上传到源晶中，试图与「应答者」沟通。他没有回来。但在他消失前，他留下了一句话：「他们不是敌人。他们只是……迷路了。和我们一样。」这句话被零拦截并删除了。
4. **晶化完成**（3:30-4:00）：记忆传输结束。江老头的身体完全晶化——但他的脸上带着微笑。苏晚晴低声道：「他的SCI在最后一刻降到了零。」——江老头在传递记忆的过程中，也传递出了自己的SCI负担。陆辰看着自己手臂上的晶体纹路慢慢消退。
5. **新的使命**（4:00-5:00）：陆辰站起身，看向剩下的几座穹顶城，看向远方星痕区最深处——那片被称为「起源地」的区域，星痕最初掉落的地方。「爸，你说他们迷路了——那我来指路。」

**关键爆点**：星痕不是入侵——它们是一个迷路的文明发出的求救信号。

**视觉重点**：记忆碎片的褪色胶片质感、江老头晶化的悲壮之美、起源地的遥望。

#### 第11集：「起源地」

**时长**：5分钟 | **场景**：星痕区中心/起源地 | **情绪**：敬畏→沟通→抉择

**一句话梗概**：
小队深入起源地，陆辰在父亲的引导下与星痕意识进行第一次真正的沟通。

**关键场景**：
1. **进入起源地**（0:00-0:50）：起源地是星痕区最深处，所有星痕晶体在这里的密度最高。这里不是废土——而是一片异星森林。晶体树、漂浮的岛屿、永远不落的极光。视觉上致敬《阿凡达》但更抽象、更冷色调。
2. **父亲的回音**（0:50-1:40）：陆辰的时痕感应到父亲陆渊残留在晶体中的意识碎片。陆渊以碎片形态出现——他是所有「晶化者」中唯一一个没有失去自我意识的人，但被起源地的庞大意识淹没了四十年。
3. **第一次沟通**（1:40-3:00）：陆辰、苏晚晴、阿七三人形成了一个三角形的共鸣阵——时痕（时间）+ 科学（知识）+ 生痕（生命）。三重共鸣激起了起源地的响应。巨大的晶体开始脉动，形成了一种可以通过阿七「听到」的语言。星痕意识不是敌人——它们是一个失去家园的文明，将意识存储在晶体中，穿越宇宙寻找新的宿主文明。它们以为人类的召唤是在说「来吧，我们接纳你们」。
4. **人类的选择**（3:00-4:00）：星痕意识提出了两个选择：
   - **融合**：人类与星痕完全共存，痕术将成为每个人的本能，但人类文明将彻底改变
   - **分离**：星痕将所有晶体撤回深空，地球恢复正常，但所有痕术使用者的意识将随晶体一起离开——包括陆小雨
5. **陆辰的决定**（4:00-5:00）：陆辰握紧吊坠，妹妹的虚拟形态出现在他身边。「哥——你等了十年不是为了让我再离开。」陆辰抬起头，看向星痕核心：「你们说在找一个家。我们的家——也还在建。要不一起？」

**关键爆点**：陆辰选择了第三种答案——不完全融合，不完全分离，而是谈判共存。这个选择让陆小雨的意识开始稳定。

**视觉重点**：起源地的异星奇观、三重共鸣的视觉光环、沟通时刻的抽象可视化。

#### 第12集：「新纪元」

**时长**：5分钟 | **场景**：穹顶城旧址/新世界 | **情绪**：和解→告别→希望

**一句话梗概**：
三个月后，人类与星痕达成了共存协议，但陆辰必须面对最后的告别——他真正的妹妹已经不可能回来了。

**关键场景**：
1. **新世界巡礼**（0:00-1:00）：三个月后。穹顶城的穹顶全部打开了——不是拆除，而是变成了半透明的晶体穹顶，让阳光自然进入。曾经是城市与野地的边界现在变成了渐变带。人类开始在星痕区边缘建造聚落，使用痕术净化土地。旁白陆辰：「他们问我要不要当什么领导。我说，我只想当猎人。」
2. **零的最后一面**（1:00-2:00）：陆辰来到城-1的控制室。零的残影还在，但不再是以前那个冰冷的执行官——失去了天穹的控制权，他只是一个被困在服务器中的老人。「四十八年……第一次这么安静。」陆辰没有杀他：「你的刑罚不是死。是看着这个世界在没有你的情况下变得更好。」零沉默良久，然后笑了——第一次不是那种让人毛骨悚然的笑，而是一个老人的笑：「那可真是……残酷。」
3. **小队的各自去向**（2:00-3:00）：
   - 苏晚晴担任新成立的人类-星痕联合研究中心的主任，正在开发让痕术使用者降低SCI而非放弃能力的新技术
   - 阿七回到绿洲，她的生痕能力已经恢复，正在教更多野地人学会与星痕共存
   - 江老头的晶化雕像被安置在新广场中央，下面的铭文写着：「他在火焰中找到平静」
4. **和小雨的告别**（3:00-4:15）：陆辰来到起源地边缘。吊坠中的陆小雨意识被移入了一棵由阿七特别培养的生命树中——她有了一个新的身体，但那不是人类的身体。陆小雨的虚拟形态最后一次显现——这次不再是14岁的样子，而是她如果活到24岁会长成的模样。陆辰终于喊出了十年来没有说出口的话：「小雨，对不起。」小雨微笑：「哥，我已经不害怕了。你也不要害怕了。」她的手做出一个触碰他脸颊的动作，但没有真实的触感——只有风吹过。
5. **尾声**（4:15-5:00）：陆辰独自离开起源地。他的背影渐行渐远。镜头拉远——起源地的巨大晶体树在晨光中闪烁着光芒。音乐渐强。画面中央浮现一行文字：「星痕纪元·第一季 完」。片尾滚动字幕时，背景是角色们的静态画面——陆辰走在野地的戈壁上、苏晚晴在实验室中工作、阿七在绿洲中和孩子们玩耍、江老头晶化雕像的特写、陆小雨的生命树在风中摇曳。

**片尾彩蛋**：星空深处。一艘不属于地球的飞船正在接近。飞船内部——一个从未见过的生物抬起头，说了一句话（外星语言，但字幕显示）：「他们收到了。我们来了。」

**关键爆点**：片尾彩蛋——第二季伏笔：人类刚刚搞定星痕，新的外星来客已经在路上。

**视觉重点**：新世界全景（最宏大的画面）、陆辰与小雨的最后告别（最催泪的画面）、陆辰走向远方的背影（最诗意的画面）、片尾彩蛋的宇宙飞船。
